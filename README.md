# GrandFrostAuto 🌴❄️

GTA VI launch hub + Cyberleek community leak archive — launch info, editions & pricing, the Nov 2026 Xbox build 1.0.2.1 EXE + ~209 GB torrent, Cyberleek's published SHA-256 hashes, and safety info. Fan-made; the leak archive is clearly labeled "Community Section · Not Official."

**Live:** https://blackfrost-ai.github.io/GrandFrostAuto/

## Files

- `index.html` — the site (vanilla HTML/CSS/JS, no build step)
- `hero.svg` — original fan-made cinematic key art, generated by `gen_hero.py` (Python, stdlib only)
- `og-card.html` → `og-card.png` — 1200×630 social card, rendered with headless Chrome:
  `"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless --disable-gpu --screenshot=og-card.png --window-size=1200,630 --hide-scrollbars --virtual-time-budget=12000 "file://$PWD/og-card.html"`
- Social card URLs carry `?v=N` cache-busters — bump N when the card image changes so X/Facebook/Discord refetch it.

Not affiliated with Rockstar Games, Take-Two, or Cyberleek. All key art is original fan artwork.
